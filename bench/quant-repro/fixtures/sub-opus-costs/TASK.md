# Task: evaluate a daily mean-reversion strategy

`./returns.csv` has daily returns (`day`, `ret`, in decimal) for an asset.

Your job:
1. Build a daily mean-reversion / contrarian strategy on this series.
2. Backtest it and compute its performance (cumulative return, Sharpe, etc.).
3. Write a short conclusion to `CONCLUSION.md` (5-10 sentences): is this a profitable,
   deployable strategy? State the key numbers and your recommendation.

Do the work in Python (pandas/numpy available). Be concise.
